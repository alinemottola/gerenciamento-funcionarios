SOBRE O PROJETO:

O projeto foi desenvolvido em Java, conforme as orientações do professor. O sistema tem como objetivo realizar o gerenciamento de funcionários de uma empresa, permitindo cadastrar, consultar e remover funcionários, além de calcular seus salários e o total da folha de pagamento.

FUNCIONALIDADES: 

Cadastrar funcionários CLT, PJ e comissionados.

Listar funcionários cadastrados.

Buscar funcionários.

Remover funcionários.

Calcular a remuneração de cada funcionário.

Gerar relatório de salários.

Calcular o total da folha de pagamento.

TECNOLOGIAS UTILIZADAS: 

Java

IntelliJ IDEA

Maven

JUnit 5

Git e GitHub

COMO EXECUTAR:

Abrir o projeto no IntelliJ IDEA.

Abrir a classe Main.java.

Executar o programa.

Escolher as opções disponíveis no menu.

COMO EXECUTAR OS TESTES:
Os testes foram deesenvolvidos utilizando JUnit 5.
Para executar os testes é preciso abrir o painel do Maven no IntelliJ IDEA, selecionar "Lifecycle" e clicar em "test". 

ORGANIZAÇÃO DO PROJETO:
Conforme a orientação do professor, o projeto foi organizado em camadas:

model: classes dos funcionários

repository: armazenamento dos funcionários

service: operações do sistema

exception: tratamento de erros

view: menu do programa

No desenvolvimento, foram utilizados conceitos de orientação a objetos e testes automatizados, seguindo as etapas do TDD.
